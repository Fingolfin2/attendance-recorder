# 手机纯文件版

如果你只是自己使用，并且希望完全不部署、不依赖电脑开机，可以使用本目录的单文件版：

- 文件：`phone-standalone/attendance-recorder.html`
- 用法：把这个 HTML 文件复制到安卓手机，在手机文件管理器中用浏览器打开。
- 数据：保存在手机浏览器对该文件的本地存储中。
- 备份：在页面“备份”中导出 JSON；换手机、换浏览器、清理浏览器数据前必须导出。

## 和 PWA 公网版的区别

优点：
- 不需要服务器。
- 不需要公网部署。
- 不需要电脑保持开机。
- 一个文件即可复制到手机使用。

限制：
- 从 `file://` 打开时，通常不能注册 service worker，因此不是真正标准 PWA。
- 不一定能像网站 PWA 一样稳定“添加到主屏幕”；不同安卓浏览器表现不同。
- 本地存储和文件路径/浏览器绑定，移动文件、换浏览器或系统清理数据可能导致看不到旧记录。

## 建议

- 最省事：直接用 `attendance-recorder.html`。
- 更像 App、可添加桌面、稳定离线：使用公网 HTTPS PWA 版本。
- 如果未来想做成真正 APK，可以再用 Android WebView/Capacitor 封装。
